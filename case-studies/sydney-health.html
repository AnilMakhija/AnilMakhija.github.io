Case study

Sydney Health: a healthcare benefits app on React Native and SwiftUI

A consumer app for insurance benefit management, claims and identity verification, used by 10K+ people. I built features in both React Native and native iOS.

My role
Software Engineer, iOS & React Native (Aug 2020 – Jul 2022)
Company
Legato Health Technologies, Bengaluru
Stack
React Native, TypeScript, Swift, SwiftUI, MVVM
Security
Biometric authentication, Keychain, OAuth2

Context

Health and insurance apps hold sensitive personal data, so authentication and storage choices matter as much as features. The product spanned iOS and Android, which is why much of it lived in a shared React Native codebase, with native SwiftUI where the platform called for it.

What I built

  • Benefit management, claims and identity-verification features.
  • Features in React Native (TypeScript) and in native SwiftUI with MVVM.
  • iOS and Android features delivered from a shared TypeScript codebase.
  • Biometric authentication, Keychain storage and OAuth2 for the app’s security model.
